# C++ Portfolio

Collection of competitive programming solutions, algorithm implementations, and utilities.

## Files

**oddSequences.cpp** - Count subsequences with odd number of 1s using distributive property (O(n))

**sortingBenchmark.cpp** - Performance comparison of 10 sorting algorithms across 4 test scenarios

**triominoes.cpp** - Divide-and-conquer solution to the L-shaped triomino tiling problem

**longJumps.cpp** - Dynamic programming solution for maximum score path on linear board

**binaryPalindrome.cpp** - Find largest number ≤ x with palindromic binary representation

**intersection.cpp** - Utility for finding common elements between sorted string vectors

**topologicalSort.cpp** - Kahn's algorithm implementation for course prerequisite ordering

**ancientGame.cpp** - Branch-and-bound solution to partition tiles into equal-sum groups
